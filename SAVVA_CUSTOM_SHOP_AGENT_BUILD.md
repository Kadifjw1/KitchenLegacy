# Савва — кастомное окно торговли

Generated feature: `savva_custom_shop_gui_v1`

## Результат

- отдельное окно магазина размером 340×220;
- семь видимых строк каталога и прокрутка колёсиком мыши;
- вкладки «Купить» и «Продать»;
- карточка выбранного товара, кошелёк, остаток и выбор количества;
- кнопки `−` и `+`;
- панель инвентаря игрока не отображается;
- ванильное окно жителя не открывается;
- все сделки повторно проверяются сервером;
- ежедневное восстановление запасов сохраняется.

## Сборка

```bash
./gradlew clean build --no-daemon
```

## Проверка в игре

```mcfunction
/worldsmith savva spawn
/time set day
```

Нажмите ПКМ по Савве основной рукой. Должно открыться кастомное окно вместо ванильного интерфейса торговли жителя.

Проверить:

1. вкладки покупки и продажи;
2. прокрутку каталога;
3. изменение количества;
4. покупку при достаточном и недостаточном количестве монет;
5. продажу при достаточном и недостаточном количестве урожая;
6. полный инвентарь;
7. исчерпание запаса;
8. восстановление запаса на следующий игровой день;
9. закрытие меню при удалении от Саввы дальше восьми блоков.

## Граница этой версии

Первое окно рисуется кодом и использует ванильные иконки предметов. Это позволяет проверить полноценную механику без неподтверждённой PNG-текстуры. Отдельная художественная текстура интерфейса может быть подключена позже без замены серверной логики торговли.
