# Савва — кастомное окно торговли

Generated feature: `savva_custom_shop_gui_v1`

## Результат

- отдельное окно магазина размером 340×220;
- семь видимых строк каталога и прокрутка колёсиком мыши;
- вкладки «Купить» и «Продать»;
- карточка выбранного товара, кошелёк, остаток и выбор количества;
- кнопки `−` и `+`;
- панель инвентаря игрока не отображается;
- ванильное окно жителя не открывается;
- все сделки повторно проверяются сервером;
- ежедневное восстановление запасов сохраняется;
- кошелёк использует `worldsmith:savva_coin`;
- каталог содержит 37 предложений;
- Савва покупает и продаёт три овоща, три ягоды и три фрукта Worldsmith.

## Сборка

```bash
./gradlew clean build --no-daemon
```

## Проверка в игре

Откройте творческую вкладку «Worldsmith: Лавка Саввы», возьмите «Призыв Саввы» и используйте его по блоку. Затем установите дневное время:

```mcfunction
/time set day
```

Нажмите ПКМ по Савве основной рукой. Должно открыться кастомное окно вместо ванильного интерфейса торговли жителя.

Проверить наличие валюты, призыва, овощей, клубники, черники, малины, груши, персика и апельсина; вкладки покупки и продажи; прокрутку; количество; оплату; продажу; недостаток валюты; заполненный инвентарь; исчерпание запаса; ежедневное восстановление; закрытие меню дальше восьми блоков.

## Граница этой версии

Окно пока рисуется кодом. Предметы используют собственные агентские PNG, но декоративная текстура самого интерфейса будет отдельным визуальным этапом.
