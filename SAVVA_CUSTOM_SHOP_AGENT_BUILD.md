# Савва — кастомное окно торговли

Generated feature: `savva_custom_shop_gui_v1`

## Результат

- отдельное окно магазина размером 340×220;
- семь видимых строк каталога и прокрутка колёсиком мыши;
- вкладки «Купить» и «Продать»;
- карточка выбранного товара, кошелёк, остаток и выбор количества;
- кнопки `−` и `+`;
- панель инвентаря игрока не отображается;
- ванильное окно жителя не открывается;
- все сделки повторно проверяются сервером;
- ежедневное восстановление запасов сохраняется;
- кошелёк использует `worldsmith:savva_coin`;
- каталог содержит 25 предложений, включая помидор, салат и огурец.

## Сборка

```bash
./gradlew clean build --no-daemon
```

## Проверка в игре

Откройте отдельную творческую вкладку «Worldsmith: Лавка Саввы», возьмите предмет «Призыв Саввы» и используйте его по блоку. Затем установите дневное время:

```mcfunction
/time set day
```

Нажмите ПКМ по Савве основной рукой. Должно открыться кастомное окно вместо ванильного интерфейса торговли жителя.

Проверить:

1. наличие монеты, помидора, салата, огурца и спавнера в отдельной вкладке;
2. вкладки покупки и продажи;
3. прокрутку каталога;
4. изменение количества;
5. покупку за монеты Саввы;
6. продажу новых овощей;
7. полный инвентарь и недостаток валюты;
8. исчерпание и ежедневное восстановление запаса;
9. закрытие меню при удалении от Саввы дальше восьми блоков.

## Граница этой версии

Окно пока рисуется кодом. Предметы уже используют собственные пиксельные PNG, но декоративная текстура самого интерфейса будет отдельным визуальным этапом.
