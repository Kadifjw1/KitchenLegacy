# «Накал»: интеграция утверждённых частиц

Используются загруженные утверждённые ассеты:

- `nakal_edge_flame_left.png` — левая кромка;
- `nakal_edge_flame_right.png` — правая кромка;
- `nakal_tip_flame.png` — кончик клинка;
- `nakal_spark.png` — искры удара;
- `nakal_ember.png` — угольки и уровни перегрева.

Постоянный огонь остаётся частью горящей item-модели и наследует её display transforms. Свободные частицы используются только для зажигания, взмахов, попаданий и теплового разрыва.

Механика не меняется: первый взмах зажигает меч, смена активного предмета гасит его.
